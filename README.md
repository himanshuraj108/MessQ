# MessQ AI — Smart Campus Mess Management

An AI-powered smart campus mess management and queue optimization Android app built with **Jetpack Compose**.

## Features
- 🍽️ Live crowd status & wait time estimation
- 📱 Pre-order meals with 3-step flow
- 🗓️ Book pickup slots
- 🤖 AI-powered assistant for menu & nutrition queries
- 📊 Hourly crowd bar chart analytics
- 🛒 Cart management with quantity controls
- 📜 Order history

## Screens
| Screen | Description |
|---|---|
| Splash | Animated LPU-branded splash screen |
| Login | Student / Staff login with tab toggle |
| Home | Dashboard with crowd status & quick actions |
| Queue Status | Live arc gauge + crowd heatmap |
| Today's Menu | Breakfast/Lunch/Dinner/Snacks with cart |
| Pre-Order | 3-step: Select → Slot → Confirm |
| Order Confirmed | Animated confirmation |
| Assistant | Smart chat with food & crowd queries |
| Order History | Past order receipts |

## Tech Stack
- **Jetpack Compose** — UI
- **Material 3** — Design system
- **Navigation Compose** — Screen routing
- **Accompanist** — System UI controller
- **Kotlin Coroutines** — Async operations

## Build
```bash
./gradlew assembleDebug
```
APK: `app/build/outputs/apk/debug/app-debug.apk`
